# Ana Health - Prototipo funcional React MVP

Prototipo navegable basado en el brief `prototipohealth.pdf`.

## Qué incluye
- Dashboard inicial con KPIs y semáforo no alarmista.
- Pantalla Hoy con registro rápido y tomas de medicación/suplementos.
- Nutrición con menú semanal y lista de compra editable.
- Entrenamiento con calendario semanal y rutina de gimnasio.
- Salud con analíticas de ejemplo y alerta de seguridad.
- Evolución con gráficos SVG internos.
- Asistente IA simulado con reglas de seguridad.
- Perfil con exportación local de datos en JSON.

## Ejecutar
```bash
npm install
npm run dev
```

Después abrir la URL local que indique Vite.

## Nota importante
Este prototipo usa datos ficticios y persistencia local en memoria del navegador. No diagnostica, no prescribe y no modifica dosis. Está diseñado para validar UX, navegación y alcance MVP antes de implementar backend, autenticación, Supabase/PostgreSQL, Prisma, RAG o almacenamiento de documentos.
